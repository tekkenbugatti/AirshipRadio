Cyberpunk-style airship you call in with a handheld "Airship Radio" tool.

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/tekkenbugatti/AirshipRadio/main/AirshipRadio.luau"))()
```

Needs an executor. LMB while holding the tool calls the ship out (press again to recall). Step into the gondola to pilot: WASD thrust, Q/E altitude, Space eject.
